# Bluetooth Priority for Windows

Bluetooth Priority is a Windows system tray app that automatically switches the default audio output when your preferred headphones or speakers become available. Put your Bluetooth headset first and your desk speakers second. When the headset disconnects, Windows can use the speakers. Reconnect the headset and automatic priority picks it again.

## Getting started

1. Extract the entire ZIP to a writable folder. The Windows x64 package includes its runtime.
2. Run **BluetoothPriority.exe**. Click the Bluetooth Priority icon in the Windows notification area to open the panel.
3. Arrange your playback devices in the order you want Windows to use them. To keep a particular output selected, click it to pin it. Click it again to resume automatic switching.

The app starts in English. You can switch to Hungarian in **Settings**. The portable edition keeps your preferences in the **Data** folder beside the executable. When updating, exit from the tray menu and keep that folder.

## What you can do

| When you want to… | Use this feature |
| --- | --- |
| Switch between Bluetooth headphones, USB audio and speakers | Set a playback priority order or pin a device from the tray. |
| Change the microphone for a call | Open the inputs view to select a recording device, adjust its volume or mute it. Applications with their own device selection may need to be set to the system default. |
| Adjust volume without opening a window | Use a global keyboard or mouse-wheel shortcut for the output or microphone. The on-screen display shows the adjustment. |
| Cycle through available audio outputs | Assign a shortcut to **Next output**. Each action accepts multiple alternative combinations. |
| Manage a paired headset | Open Bluetooth connections to request a connection or disconnection. Battery level and microphone gain appear when the device and driver expose them. |

## Keyboard and mouse shortcuts

| Action | Default |
| --- | --- |
| Volume up or down | Ctrl + Shift + mouse wheel up or down |
| Switch the volume controls between output and microphone | Ctrl + Shift + F10 |
| Select the next output | Choose your own shortcut |

In **Settings → Edit shortcuts**, choose **+** beside an action, press your combination or scroll one step, then save. For example, you can assign **Ctrl + wheel** to volume. This takes over a gesture many browsers use for zoom, so choose a different modifier if you use both.
